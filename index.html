교원 호봉획정부터 호봉정정 급여정산까지. 올린 자료는 이 컴퓨터 안에서만 계산됩니다.

버전 2026.09.30 c  — 예전에 받아 둔 파일이 있으면 지우고 이 파일로 쓰세요.

업무 흐름  증빙서류 → ① 바로호봉(호봉획정표 작성) → 호봉 정정·재획정 → ② 바로봉(추가지급·환수액 계산)
① 호봉을 정할 때

바로호봉 · 교원 호봉획정 계산기

서류를 한꺼번에 올리면 쪽마다 무슨 서류인지 알아서 가려내 호봉을 계산합니다.

  • 교원자격증·졸업증명서·경력서류·호봉획정표를 읽어 자동 입력 (PDF·사진)
  • 직전 호봉획정표가 있으면 환산율까지 그대로 가져옴
  • 주민등록번호·생년월일·주소는 읽는 단계에서 지움
  • 환산율 찾기 — ‘학원’, ‘군대’처럼 한 낱말만 넣으면 환산율과 근거 조항 표시 (단추로도 바로 찾기)
  • 등기사항전부증명서·사업자등록증·학칙 등 경력이 아닌 서류는 자동으로 걸러 냄
  • 기간 중복 경고 · 겹치는 경력 한쪽만 인정
  • 결과에 “어떻게 이 호봉이 나왔나요?” 계산방법 설명
  • 차기 승급일 계산, 호봉획정표 인쇄·PDF
② 호봉이 바뀐 뒤 정산할 때

바로봉 · 호봉정정 급여정산

나이스 급여 파일과 호봉획정표를 올리면 추가지급·환수액을 월별로 계산합니다.

  • 나이스 연도별 급여 파일 여러 개 한꺼번에 읽기
  • 호봉획정표(PDF·사진)에서 호봉·잔여기간 자동 인식
  • 본봉·정근수당·명절휴가비 등 호봉 연동 항목 차액 계산
  • 결과보고서 인쇄·PDF, 엑셀 저장
